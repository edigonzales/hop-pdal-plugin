[[point-cloud-calculator]]
= Point Cloud Calculator
:plugin-id: SOGIS_POINTCLOUD_CALCULATOR
:plugin-type: transform
:description: Calculate dimensions with value, range or condition assignments (for example Foo = Z * 2)

The Point Cloud Calculator computes new or existing dimensions. The PDAL `assign` filter supports value expressions, range based assignments and optional conditions.

== Description

Calculate dimensions with value, range or condition assignments (for example Foo = Z * 2)

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output field
|Optional new value field; empty updates the input field in place.
|(empty)

|Assignment kind
|`VALUE` for expressions (`Foo = Z * 2`), `ASSIGNMENT` for range assignments (`Classification[:]=2`).
|`VALUE`

|Assignment
|The expression or range assignment.
|(empty)

|Condition
|Optional range condition for the assignment.
|(empty)

|Condition
|Optional `where` expression that limits the assignment to a subset of points.
|(empty)
|===

== Output

The Point Cloud value with the appended `filters.assign` stage. New dimensions from `Name = ...` expressions are added to the planned schema.

== Supported engines

Planning only: this transform appends a stage to the pipeline plan and runs on the Hop local engine
without native access. The plan is executed by the Point Cloud Writer in a single PDAL call.

== Examples

* `examples/05-filter-calculator.hpl` computes a normalised intensity dimension.

== Error handling

Enable error handling to route rows with invalid settings or missing values to an error transform.

== Limitations

Dimension names must be valid provider names (letters, digits, underscore). Nested expressions and dimensional analysis beyond the PDAL expression language are not available.
