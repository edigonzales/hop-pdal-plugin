[[point-cloud-thin]]
= Point Cloud Thin
:plugin-id: SOGIS_POINTCLOUD_THIN
:plugin-type: transform
:description: Thin a point cloud by decimation, voxel, grid, sampling or farthest point sampling

The Point Cloud Thin transform reduces the number of points with one of five PDAL algorithms.

== Description

Thin a point cloud by decimation, voxel, grid, sampling or farthest point sampling

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output field
|Optional new value field; empty updates the input field in place.
|(empty)

|Algorithm
|`DECIMATION`, `VOXEL_DOWNSIZE`, `GRID_DECIMATION`, `SAMPLE` or `FPS`.
|`DECIMATION`

|Step
|Keep every Nth point (decimation).
|(empty)

|Voxel cell
|Cell size in CRS units (voxel downsize).
|(empty)

|Voxel mode
|`first`, `center` or `centroid` (voxel downsize).
|`first`

|Grid cell
|Grid resolution (grid decimation).
|(empty)

|Sample radius
|Minimum distance between points (Poisson sampling).
|(empty)

|FPS count
|Number of points to keep (farthest point sampling).
|(empty)

|Condition
|Optional `where` expression that limits the filter to a subset of points.
|(empty)
|===

== Output

The Point Cloud value with the appended thinning stage. The planned point count becomes unknown.

== Supported engines

Planning only: this transform appends a stage to the pipeline plan and runs on the Hop local engine
without native access. The plan is executed by the Point Cloud Writer in a single PDAL call.

== Examples

* `examples/07-thin-outlier.hpl` thins a source down to a voxel grid.

== Error handling

Enable error handling to route rows with invalid settings or missing values to an error transform.

== Limitations

The algorithms have different semantics: decimation keeps every Nth point, voxel downsize keeps one point per cell and sampling enforces a minimum distance.
