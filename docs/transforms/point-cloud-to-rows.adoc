[[point-cloud-to-rows]]
= Point Cloud to Rows
:plugin-id: SOGIS_POINTCLOUD_TO_ROWS
:plugin-type: transform
:description: Execute a point cloud and emit one Hop row per point with block-wise dimension reads

The Point Cloud to Rows transform executes the planned pipeline and converts the points into
ordinary Hop rows, one row per point, with the selected dimensions as fields.

== Description

The transform opens the point cloud plan through the block-wise point view API
(`Pdal.open`): the pipeline runs in standard mode and the points stay in native memory. Blocks of
65536 points are copied into Java arrays, so the JVM heap and the garbage collector are not
flooded by a whole point cloud. One row per point is emitted for every block.

Fields declared by the transform: one field per selected dimension (`<prefix><dimension>`),
floating point dimensions as Number and integer dimensions as Integer. The input fields (including
the Point Cloud value) are passed through unchanged, so the source of a point row stays traceable.

Use this transform for exports, quality checks or joins that need per point values. For large point
clouds reduce the data first (Point Cloud Thin, Range or Crop) - one row per point can produce
millions of rows.

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader and planned by
crop, filter or ground transforms.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Dimensions
|Comma separated dimensions to emit as fields (for example `X,Y,Z,Classification`).
|(empty)

|Integer dimensions
|Comma separated dimensions that are emitted as Integer (for example `Classification,Intensity`);
all other dimensions are emitted as Number.
|(empty)

|Field prefix
|Prefix of the emitted dimension fields.
|(empty)

|Maximum points
|Optional safety limit: rows with more points fail instead of flooding the pipeline.
|(empty)
|===

== Output

The input fields plus one field per selected dimension, one row per point.

== Supported engines

This transform executes the bundled PDAL runtime and runs on the Hop local engine with native
access. The pipeline is executed here; a following Point Cloud Writer would execute it again.

== Examples

* `examples/13-point-cloud-to-rows.hpl` emits X, Y, Z and Classification of a source as rows.

== Error handling

Enable error handling to route rows with unknown dimensions or point counts above the limit to an
error transform.

== Limitations

The plan is executed in this transform. One row per point means many rows for large point clouds;
use *Maximum points* as a guard and thin the data first.
