[[point-cloud-crop]]
= Point Cloud Crop
:plugin-id: SOGIS_POINTCLOUD_CROP
:plugin-type: transform
:description: Plans a bounds crop of a point cloud.

The Point Cloud Crop transform appends a `filters.crop` stage to the pipeline plan of a Point Cloud
value. Nothing is executed: the crop runs when the Point Cloud Writer executes the complete plan.

== Description

The crop is defined by two dimensional bounds in the CRS of the source. When `minz` and `maxz` are
set as well, a three dimensional crop is planned. The bounds can be fixed values or read from input
fields, which allows one crop per row.

The transform updates the planned schema: the bounds of the value become the intersection of the
source bounds and the crop region, and the point count is marked as unknown until the write step.

Multiple crops, reprojections and further filter transforms can be chained before the writer
executes the accumulated pipeline exactly once.

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output field
|Optional name of a new value field; empty updates the input field in place.
|(empty)

|Bounds are fields
|Read the bounds from the named input fields instead of using fixed values.
|`N`

|minX, minY, maxX, maxY
|Two dimensional crop bounds in the source CRS.
|

|minZ, maxZ
|Optional vertical crop bounds; both empty plans a two dimensional crop.
|(empty)
|===

== Output

The Point Cloud value with the appended crop stage, either in a new field or updated in place.

== Supported engines

This transform runs on the Hop local engine; the actual crop is executed by the Point Cloud Writer
through the bundled PDAL runtime.

== Examples

* `examples/02-crop.hpl` crops a source to a fixed bounding box and writes the result.

== Error handling

Enable error handling to route rows with missing bounds, invalid values or non-overlapping regions
to an error transform.

== Limitations

Only axis aligned bounds are supported in V1. Polygon or geometry based crops follow once Hop
geometry values are linked in.
