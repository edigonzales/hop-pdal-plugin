[[point-cloud-writer]]
= Point Cloud Writer
:plugin-id: SOGIS_POINTCLOUD_WRITER
:plugin-type: transform
:description: Executes the planned pipeline once and writes the result to a file.

The Point Cloud Writer is the execution point of the point cloud transforms. It appends a writer
stage to the pipeline plan and runs the complete plan exactly once.

== Description

Upstream transforms only plan stages (reader, crop, reprojection, ...). The writer adds the PDAL
writer stage that matches the output extension and executes the accumulated pipeline once, for
example `readers.las → filters.crop → filters.reprojection → writers.las`. Intermediate results are
never written to disk and points are never moved between Java and native code.

The transform adds two fields to the row: the written file name and a status field.

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader and further
planned by crop/reproject transforms.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output file
|Target path; the PDAL writer stage is inferred from the extension (`.las`, `.laz`, `.copc.laz`,
`.bpf`, `.ply`, text formats, `writers.gdal`).
|

|Output is a field
|Read the output path from the named input field instead of using a fixed value.
|`N`

|Overwrite
|Replace an existing file.
|`N`

|Field prefix
|Prefix for the status fields.
|(empty)

|Compression
|LAS compression (`laszip`, `lazperf`, `deflate`); LAS/LAZ output only.
|(empty, default)

|Minor version
|LAS minor version (2, 3 or 4); LAS/LAZ output only.
|(empty, default)

|Extra dimensions
|Extra dimensions to write, for example `all` or `Foo=float`; LAS/COPC output only.
|(empty)

|Override CRS
|CRS written to the file (`a_srs`); empty uses the planned CRS of the value.
|(empty)

|Threads
|Writer threads; COPC output only.
|(empty, default)

|Header forward
|LAS/COPC header fields to forward from the source (for example `header`, `scale`, `vlr`).
|(empty)
|===

== Output

The input row plus `<prefix>output_file` and `<prefix>status`. The Point Cloud value is passed
through unchanged.

== Supported engines

This transform executes the bundled PDAL runtime on the Hop local engine. Java 25 and
`--enable-native-access=ALL-UNNAMED` are required.

== Examples

* `examples/01-read-write.hpl` writes a source without further processing.
* `examples/02-crop.hpl` writes a cropped source.

== Error handling

Enable error handling to route rows with unwritable paths or PDAL execution errors to an error
transform; the error message contains the PDAL log excerpt.

== Limitations

One writer per pipeline is recommended. Writing to the original source is rejected by PDAL when the
file is open for reading. Optional writer plugins (E57, TileDB, ...) are not part of the standard
bundle.
