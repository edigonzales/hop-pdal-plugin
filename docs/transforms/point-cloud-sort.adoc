[[point-cloud-sort]]
= Point Cloud Sort
:plugin-id: SOGIS_POINTCLOUD_SORT
:plugin-type: transform
:description: Sort points by dimensions or Morton code

The Point Cloud Sort transform orders the points, which often improves compression of the written file.

== Description

Sort points by dimensions or Morton code

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output field
|Optional new value field; empty updates the input field in place.
|(empty)

|Morton order
|Use the Morton (Z-order) curve instead of dimension sorting.
|`N`

|Morton reverse
|Reverse the Morton order.
|`N`

|Dimensions
|Comma separated provider dimensions (sorting only).
|(empty)

|Descending
|Sort descending (sorting only).
|`N`

|Condition
|Optional `where` expression that limits the filter to a subset of points.
|(empty)
|===

== Output

The Point Cloud value with the appended `filters.sort` or `filters.mortonorder` stage. Bounds and point count stay unchanged.

== Supported engines

Planning only: this transform appends a stage to the pipeline plan and runs on the Hop local engine
without native access. The plan is executed by the Point Cloud Writer in a single PDAL call.

== Examples

* `examples/08-sort-transform.hpl` sorts a source by height before writing.

== Error handling

Enable error handling to route rows with invalid settings or missing values to an error transform.

== Limitations

The sort is applied while executing the pipeline; it does not create an index that could be queried later.
