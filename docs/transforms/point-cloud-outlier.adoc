[[point-cloud-outlier]]
= Point Cloud Outlier
:plugin-id: SOGIS_POINTCLOUD_OUTLIER
:plugin-type: transform
:description: Remove outliers with statistical or radius based methods

The Point Cloud Outlier transform removes isolated points using the statistical or the radius based PDAL outlier filter.

== Description

Remove outliers with statistical or radius based methods

== Input

A field with the Hop type `Point Cloud`, usually produced by the Point Cloud Reader.

== Options

[cols="1,3,1",options="header"]
|===
|Option |Description |Default

|Point Cloud field
|Name of the input field.
|`pointcloud`

|Output field
|Optional new value field; empty updates the input field in place.
|(empty)

|Method
|`STATISTICAL` (mean distance of neighbours) or `RADIUS` (minimum neighbours in a radius).
|`STATISTICAL`

|Mean k
|Number of neighbours for the statistical method.
|`8`

|Multiplier
|Standard deviation multiplier for the statistical method.
|`2.0`

|Radius
|Search radius for the radius method.
|(empty)

|Min k
|Minimum number of neighbours inside the radius.
|`2`

|Condition
|Optional `where` expression that limits the filter to a subset of points.
|(empty)
|===

== Output

The Point Cloud value with the appended `filters.outlier` stage. The planned point count becomes unknown.

== Supported engines

Planning only: this transform appends a stage to the pipeline plan and runs on the Hop local engine
without native access. The plan is executed by the Point Cloud Writer in a single PDAL call.

== Examples

* `examples/07-thin-outlier.hpl` removes statistical outliers before thinning.

== Error handling

Enable error handling to route rows with invalid settings or missing values to an error transform.

== Limitations

Outlier detection loads neighbour structures in native memory; very large point clouds need corresponding RAM.
